# Portfólio Front-End — Yuri Rafael Santos de Araújo

Este projeto apresenta um portfólio profissional moderno, responsivo e preparado para vagas tecnológicas de alto padrão. A interface foi construída com React, Vite, TypeScript e uma stack de ferramentas orientada a performance, acessibilidade, UX e escalabilidade.

## Stack principal

- React
- Vite
- TypeScript
- React Router
- Tailwind CSS
- Framer Motion
- TanStack Query
- React Hook Form
- Zod
- Axios
- Lucide React

## Como executar

```bash
npm install
npm run dev
```

```bash
npm run build
```
